About [[(GDPR) General Data Protection Regulation]]

Data mapping is the process of record-keeping customer data collected by an organisation. It aims to identify and verify data processing, such as collection, use, storage, and sharing. It is performed to understand how data flows in your organisation.

Key elements:
* Personal data categories
* Purpose of data processing
* Data sources and third-party involvement
* Data storage and security
	* Ensure data is stored securely, protected from breaches, and retained only as long as necessary. Clearly communicate retention policies to users.
* Data transfer and data protection

Conduct [[(DPIA) Data protection Impact Assessments for GDPR]]

Requirements of data mapping:
* Records of Processing Activities (ROPA)
* Lawful basis for processing
* Data minimisation and purpose limitation
* Data security
* Data subject rights
* Third party and cross border transfers

There are tools like Talend, Skyvia, Datagrail or IBM App connect
