## Notes Box
```dataview
TABLE
	reference as "Reference",
	Date as "Date"
FROM
    "100 Notes Box"
WHERE 
    Date >= date(this.Date) AND Date <= date(this.EndDate)
SORT file.Date ASC

```

## Files Created
```dataview
TABLE
	tags as "Tags"
FROM "" AND !"100 Notes Box"
WHERE 
    file.cday >= date(this.Date) AND file.cday <= date(this.EndDate)
SORT file.tags ASC
```
