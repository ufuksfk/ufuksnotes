## Highlights
- [Project import and export](https://docs.gitlab.com/ee/user/project/settings/import%5Fexport.html) can be used to effectively create project-level templates, making it easy to create and replicate more complex workflows. Project exports include everything in the project, including issues and files, making it a powerful tool for sophisticated workflows.
