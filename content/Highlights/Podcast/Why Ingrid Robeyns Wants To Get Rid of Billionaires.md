# Note
 I believe that extreme wealth is a problem and that we should have a limit on how much wealth a person can have. I call this concept "limitarianism." I argue that no one should have more than, say, £10 million. I think that large amounts of wealth are almost always dirty and that we could use that money for better purposes. I think that we should move to a society and an economy that meets basic needs and that does so within planetary boundaries. I think that we need to move to a different economic system, one that is more sustainable and equitable. I believe that we need to have a discussion about how to create a new socioeconomic system that is more just and sustainable. I think that we need to change our ideology and that we need to have a new way of thinking about wealth and inequality. I believe that we can create a better world, but we need to act now.
